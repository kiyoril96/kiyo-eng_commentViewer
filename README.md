### Powerd by  [わんコメ](https://onecomme.com/) 

### これは何？
* アセットコルサのゲーム内でYoutubeやTwitchなどの各配信サイトのライブコメントを表示できるアプリです。
*  [わんコメ](https://onecomme.com/)  という別のアプリを使います。（このアプリがわんコメの拡張機能に当たります。）
  * 幣アプリは無料版の範囲で利用できます。

### 別に画面出して見ればよくね？
* ~~と思ったあなたには不要です。~~
* VRや3画面でのプレイを配信するような用途を想定しています。  
  * 1画面しかない・3画面でプレイしつつ配信したい（別アプリを表に出すと邪魔）
  * VR中でもコメントが見たい（そもそも見る方法が少ない）
  * といった要望に応えられるかと思います

### ダウンロード・インストール
* Releaseより最新のリリースファイルを取得してください。 
* CMにD＆Dでインストールか ~/AssettoCorsa/ に展開してご利用ください。

### 使い方
* わんコメは通常通りセットアップしてください。
* ゲーム内でアプリを起動すると、すでにわんコメが起動していれば自動的に接続されます。
  * 起動していなければ「Disconnected」表示になります。起動させてください。
* わんコメで配信に接続、「書き出し」がONになっていればゲーム内からコメントが見えるはずです。
* ゲーム内アプリの右上の歯車マークから設定ができます。
  * Template ：わんコメのテンプレートです。好きなものを選んでください。（OBSとは別で指定できます。）
  * Size：表示倍率です。
  * カスタムテンプレートも追加すれば使えるはず。たぶん。
